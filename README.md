# Botely Robot

## Overview

Botely is an educational robotic platform designed to introduce children to fundamental programming concepts through an engaging, hands-on experience. The robot enables users to create sequences of movement instructions using simple directional commands, allowing children to develop logical thinking and problem-solving skills without requiring prior programming knowledge.

The project aims to bridge the gap between play and education by transforming abstract programming concepts into tangible actions that can be observed in real time.

## How It Works

Users provide a sequence of movement instructions to the robot using dedicated directional controls.

Example command sequence:

```
Forward → Forward → Left → Forward → Right
```

The robot stores the entered commands and executes them one after another, allowing children to observe how individual instructions combine to achieve a larger goal.

Through repeated interaction, users naturally develop an understanding of concepts such as:

- Sequencing
- Algorithmic thinking
- Planning
- Debugging and error correction
